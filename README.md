## Selected projects

### [Toronto Neighbourhood Safety Index Forecasting](https://github.com/skylarrrskr/toronto-nsi-predict)
**Team research project · Python · Feature engineering · Forecasting**

Our team used public crime data to forecast a safety index one month ahead for 158 Toronto neighbourhoods. I built features from the previous one to three months of crime data. We compared four models using time-based splits, and XGBoost achieved a test R² of 0.818.

[Project report](https://github.com/skylarrrskr/toronto-nsi-predict/blob/main/reports/report.md) · [Lagged feature code](https://github.com/skylarrrskr/toronto-nsi-predict/blob/main/src/data_preprocessing/lagged_features.py)

### [Credit Risk Analytics Agent](https://github.com/skylarrrskr/credit-risk-analytics-agent)
**Personal prototype · Python · SQL · SQLite · OpenAI API**

I built a command-line prototype that turns plain-English questions into structured SQL plans. It uses synthetic customer, loan, and payment data to answer questions such as which customer segment has the highest delinquency rate.

[Planner implementation](https://github.com/skylarrrskr/credit-risk-analytics-agent/blob/main/src/llm_planner.py)

### [Planetze — Carbon Footprint Tracker](https://github.com/skylarrrskr/Planetze)
**Team lead · Android · Java · Firebase**

I led a four-person team in a software engineering course to build an Android app that estimates users' carbon footprints. Users can log daily activities, see how their emissions change over time, and review suggestions for reducing them. The app stores activity logs in Firebase.
